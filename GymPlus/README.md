# GymPlus - Modern Gym Landing Page

A responsive, feature-rich gym landing page built with React.js (Vite) and Tailwind CSS. This project demonstrates modern web development practices with a focus on performance, responsiveness, and user experience.

![GymPlus Screenshot](src/assets/images/hero-bg.jpg)

## 🚀 Features

- **Modern Design**: Clean, professional, and energetic design that captures the essence of a premium gym.
- **Fully Responsive**: Optimized for all devices - mobile, tablet, and desktop.
- **Interactive Elements**: Subtle animations, hover effects, and transitions enhance user experience.
- **Component-Based Architecture**: Modular, maintainable code structure using React functional components.
- **Performance Optimized**: Fast loading with optimized assets and code splitting.
- **Form Validation**: Interactive contact form with client-side validation.
- **Accessibility**: Semantic HTML and ARIA attributes for inclusive user experience.

## 📋 Sections

- Dynamic Header with Mobile Navigation
- Bold Hero Section
- Programs Overview
- Membership Plans
- Trainer Profiles
- Contact Form with Validation
- Detailed Footer

## 🛠️ Technologies Used

- **React.js**: UI components and state management
- **Vite**: Fast development and optimized builds
- **Tailwind CSS**: Utility-first styling
- **Framer Motion**: Smooth animations and transitions
- **React Router DOM**: Navigation and routing
- **React Icons**: Comprehensive icon library

## 🔧 Setup & Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/yourusername/gymplus.git
   cd gymplus
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Start development server**

   ```bash
   npm run dev
   ```

4. **Build for production**

   ```bash
   npm run build
   ```

5. **Preview production build**
   ```bash
   npm run preview
   ```

## 📱 Responsive Design

- **Mobile**: Single column layout, hamburger menu, adjusted font sizes
- **Tablet**: Two-column grids, expanded navigation
- **Desktop**: Multi-column layouts, hover effects, larger visuals

## 🎨 Customization

- Edit `tailwind.config.js` to modify colors, fonts, and other theme settings
- Update mock data in the `src/data` folder
- Replace images in `src/assets/images`
